二、详细安装教程：跨平台全攻略

Android设备安装详解

  1. 安全下载：建议从GitHub官方仓库获取APK，避免第三方渠道的篡改风险。安装前需开启"允许未知来源应用安装"选项（设置→安全→特殊应用权限）。
  2. 权限配置：首次启动时，务必授予VPN连接权限，这是实现全局代理的关键。系统可能会弹出安全警告，这是正常现象，选择"确认"即可。
  3. 兼容性处理：针对MIUI等深度定制系统，需要在"电池优化"设置中将v2rayng设为不优化，防止系统自动清理后台导致断连。

Windows系统部署指南

  1. 环境准备：推荐Windows 10 1903及以上版本，确保.NET Framework 4.8运行库已安装。部分安全软件可能误报，需提前添加信任。
  2. 便携式安装：解压后可直接运行的绿色版特性是其亮点，但建议将文件夹放置在非系统盘（如D:\Tools\v2rayng），避免权限问题。
  3. 服务化运行：高级用户可通过NSSM工具将其注册为系统服务，实现开机自启（命令：nssm install v2rayng）。

路由规则深度定制

通过编辑rules.json文件，可以实现精细化的流量控制：
json { "domainStrategy": "IPIfNonMatch", "rules": [ { "type": "field", "outboundTag": "direct", "domain": ["geosite:cn"] }, { "type": "field", "outboundTag": "proxy", "network": "tcp,udp" } ] } 此配置实现国内直连、国外代理的智能分流，可节省约40%的代理流量。

FAQ

Trojan-Go 的多路复用（mux）如何开启？
Trojan-Go 在配置文件中通过启用 mux 参数即可实现多路复用。此功能允许多个连接共享同一隧道，减少握手延迟并提升整体传输效率，尤其在移动网络中表现出色。
VLESS + XTLS 在移动网络的优势？
XTLS 模式减少握手次数和加密开销，适合高延迟或不稳定的移动网络。结合策略组和多节点切换，可提升网页浏览、视频播放和游戏的连接稳定性和流畅度。
VLESS + XTLS 在高延迟移动网络的优势？
XTLS 模式减少握手次数和加密开销，适合高延迟或不稳定移动网络。结合策略组和节点切换，可提高网页浏览、视频播放和游戏连接的稳定性和流畅度。
VMess 使用 TLS+WebSocket 的好处是什么？
TLS+WebSocket 可伪装成正常 HTTPS 流量，增强抗封锁能力和隐蔽性。结合域名伪装和策略组使用，可在高封锁网络环境下保持安全、稳定和高速的网络访问体验。
Mihomo 的 Web Dashboard 有哪些功能？
Mihomo 的 Web 控制面板允许用户可视化管理节点、分流规则、日志查看与系统状态监控。可通过浏览器访问 Dashboard 地址进行远程管理，方便多设备统一控制。
V2Ray 的 Reality 功能是什么？
Reality 是 V2Ray 新增的伪装技术，可替代传统 TLS。它无需真实证书，通过公钥验证机制实现端到端加密。相比 Trojan 的 HTTPS 伪装方式，Reality 更轻量、安全且配置更简洁。
Nekobox 如何在 Android 上导入配置？
打开 Nekobox，点击“导入配置”按钮，选择订阅链接或本地 JSON 文件。程序会解析后自动生成节点列表，用户可一键连接或测速筛选最优节点。
VLESS + XTLS 对高延迟网络有哪些优化？
XTLS 模式减少握手和加密开销，适合高延迟或不稳定网络环境。结合策略组和节点切换，可提高网页浏览、视频播放和游戏的稳定性和流畅度，改善用户体验。
Surfboard 的规则导入失败可能是什么原因？
可能是规则格式不兼容、语法错误或策略组缺失。确保导入文件符合 Surfboard 的 YAML 规范，并检查节点或策略组是否完整，可解决导入失败问题。
Netch 的 TCP/UDP 分流适合哪些应用？
TCP 分流适合网页、下载和视频播放，UDP 分流适合游戏、语音和实时视频。Netch 可同时代理 TCP 和 UDP 流量，实现精准分流，保证不同应用的最佳性能。
