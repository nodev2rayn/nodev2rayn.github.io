一、Quantumult X 是什么？它的定位远超代理工具

Quantumult X（以下简称QX）不仅仅是一个普通的代理客户端，它是一套网络管理解决方案。其核心定位是——为用户提供完整、透明、可控的网络请求处理逻辑。

在安卓版本中，QX保留了大部分iOS核心功能，并加入了一些平台特性，让安卓用户也能享受到高级代理技术带来的便利与自由。

核心能力概览：

  • 支持多协议代理：包括 HTTP、HTTPS、SOCKS5、Shadowsocks、Vmess 等。

  • 灵活的规则配置系统：支持根据域名、IP、关键词等设定行为逻辑。

  • 自定义 DNS 服务：提高解析速度，绕过DNS污染。

  • 分流与重定向支持：可将不同应用或网站的流量分配给不同的节点或策略。

  • 实时流量监控和日志记录：网络行为透明可见，方便排错与优化。

  • 自动更新订阅与规则集：支持外部订阅链接，轻松实现节点批量管理。

在功能层级上，QX几乎达到了商用级别的网络管理水平，却以极简的方式呈现给终端用户，可谓“简洁中见锋芒”。

三、Quantumult X 配置实战：从零开始掌握核心能力

真正让Quantumult X发挥价值的，是它强大的配置系统。以下将从基础代理设定开始，一步步讲解如何打造属于你的QX网络规则体系。

1. 添加代理服务器节点（节点来源）

要实现科学上网，首先需要代理节点。节点来源一般有三种：

  • 购买付费节点订阅（推荐）：如Clash、V2ray、Trojan等服务商提供的订阅链接，稳定、安全。

  • 使用免费分享节点：不稳定，安全性低，适用于测试和临时访问。

  • 自建节点：成本高但可控，适合高阶用户。

导入方式：

  • 打开Quantumult X主界面，点击右上角“+”，选择“通过订阅链接导入”；

  • 粘贴你的订阅链接；

  • 导入后会自动更新节点列表。

2. 设置DNS服务器

DNS 是网络访问中的第一步，决定了你能否顺利访问目标网站。

推荐配置：

  • Cloudflare DNS：1.1.1.1 / 1.0.0.1

  • Google DNS：8.8.8.8 / 8.8.4.4

在设置中手动输入DNS地址，建议开启 DNS-over-HTTPS 或 DNS-over-TLS，防止DNS污染。

3. 自定义规则分流

这是Quantumult X最有价值的部分。你可以将如下流量自动分流：

  • 国内网站 → 直连

  • 国际网站（如Twitter、YouTube）→ 走代理

  • 广告域名 → 拦截

  • 游戏类请求 → 分配特定节点（如低延迟日本节点）

示例规则：

ini
[filter]
IP-CIDR,192.168.0.0/16,DIRECT
DOMAIN-SUFFIX,twitter.com,Proxy
DOMAIN-KEYWORD,google,Proxy
GEOIP,CN,DIRECT
FINAL,Proxy

规则执行顺序从上到下，最后一条是“兜底规则”，未命中其他规则的流量将默认走 Proxy。

4. 快速启用和切换代理

在主界面中可快捷开启/关闭代理服务，还可在不同代理策略之间切换。

建议模式：

  • 工作时：规则分流

  • 下载大文件或看视频时：全局代理

  • 网络调试时：直连或记录日志模式

FAQ

Clash 如何防止规则文件冲突导致分流异常？
合理组织规则顺序，将更具体的规则放在前面，通配规则放在末尾；使用 rule-providers 分离不同来源的规则，避免重复条目，并在变更后使用日志或 debug 模式检验分流是否按预期生效。
Nekobox 能否使用订阅链接？
Nekobox 支持通过订阅 URL 导入节点。用户在应用中选择“添加订阅”，输入链接后系统会自动更新节点数据，并支持定期刷新，确保始终使用最新线路。
Shadowrocket 的节点测速结果如何应用？
节点测速结果可用于策略组选择和自动切换，程序会根据延迟和丢包率选择最优节点。这样访问海外网站或流媒体时，可以保持高速和稳定的网络体验。
VMess 与 Shadowsocks 哪个更安全？
VMess 使用动态认证机制，防止重放攻击，而 Shadowsocks 依赖静态密钥。总体来说，VMess 的安全性更强，尤其在应对 DPI 检测和中间人攻击时表现更优。
Hysteria2 多路复用如何提升短连接性能？
多路复用允许多个短连接共享同一通道，减少握手延迟和资源消耗。适合高频短连接场景，如游戏和即时通讯，可提高吞吐量和连接稳定性，优化整体网络体验。
如何用 systemd 管理 V2Ray/ Sing-box 服务？
创建 systemd 单元文件，指定 ExecStart 指令并设置 Restart=on-failure 与合适的 User/Group。启用服务并使用 `systemctl enable` 与 `systemctl start` 管理，便于开机自启与日志集中收集。
Hysteria2 如何提升网速？
Hysteria2 利用 QUIC 协议的低延迟特性，并通过自适应拥塞控制算法在高丢包网络下维持高速连接。配置合适的带宽参数与 TLS 证书，可显著提升跨境访问速度。
Hiddify Next 如何设置用户带宽限制？
管理员可为每个用户设置独立带宽和流量配额，超出时可自动降速或阻止访问。这样可确保服务器资源合理分配，避免单用户占用过多带宽，提高整体网络效率和公平性。
Surfboard 是否支持应用分流？
支持。Surfboard 可通过策略组和规则文件将不同应用流量分配到指定节点，保证游戏、视频和浏览器流量走最优节点，提高访问速度和网络稳定性。
VLESS 相比 VMess 的主要改进是什么？
VLESS 是 VMess 的后继协议，移除了加密层以减少服务器资源消耗，同时提供更灵活的加密与传输方式选择。它更轻量、可扩展性更好，常被用于与 XTLS 等新传输协议搭配使用。
